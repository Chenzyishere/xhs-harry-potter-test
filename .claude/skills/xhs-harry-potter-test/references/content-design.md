# 内容设计：让结果"像自己"

这个产品成败的 80% 在这一页。代码只是容器。

## 一、先想清楚：分院帽天然只有 4 个结果

历史人物题材是 16 个结果，分院帽只有 **4 个学院**。这带来一个本质差异：

| | 16 人物 | 4 学院 |
|---|---|---|
| 内容厚度 | 厚 | 薄 |
| 身份认同 | 中（"我像苏轼"） | **极强**（"我是格兰芬多"） |
| 晒图欲 | 高 | **更高**（学院是身份标签，有归属感） |

**结论：4 结果的内容薄，靠"身份认同 + 晒图欲"补回来。** 所以每个学院的文案要写得比 16 人物更重、更"戳"，不能因为是学院就偷懒。

## 二、四维模型

### 为什么用双极维度

不要用"勇气强/弱"这种单向维度。单向维度会导致**中间态不可达**，部分学院永远匹配不到。

双极维度让每个学院落在四维空间的某个位置，用户也在同一空间里，算欧氏距离取最近。

### 四维（对应四学院精神）

```
D1  勇气(+) / 谨慎(-)    敢不敢冒险、挺身而出   → 格兰芬多向
D2  野心(+) / 淡泊(-)    想不想赢、争不争       → 斯莱特林向
D3  理性(+) / 感性(-)    靠逻辑还是靠直觉       → 拉文克劳向
D4  忠诚(+) / 自我(-)    为集体还是为自己       → 赫奇帕奇向
```

### 学院向量

每个学院在四维空间里的落点，必须落在各自的"角落"里，彼此拉开距离：

```
格兰芬多  [ 0.8,  0.2, -0.3,  0.4]   ← 高勇气、中野心、偏感性、中忠诚
斯莱特林  [ 0.3, 0.85,  0.4, -0.75]  ← 中勇气、高野心、偏理性、偏自我
拉文克劳  [-0.35,-0.3,  0.9,  0.1]   ← 偏谨慎、淡泊、高理性
赫奇帕奇  [-0.45,-0.55,-0.15, 0.85]  ← 偏谨慎、淡泊、偏感性、高忠诚
```

四向量分处四个象限，保证每个都可达。

### 学院专属色

| 学院 | 主色 | 代表 |
|---|---|---|
| 格兰芬多 | 猩红 `#a82723` | 狮子 |
| 斯莱特林 | 墨绿 `#1a6e50` | 蛇 |
| 拉文克劳 | 宝蓝 `#2f5d8f` | 鹰 |
| 赫奇帕奇 | 金黄 `#d4a017` | 獾 |

结果页、分享卡、雷达图都用学院专属色，一眼认出来。

## 三、写题目

### 唯一原则：具体，有画面感，带魔法场景

```
✅ 深夜的禁林传来奇怪的响动，你会？
   A 带上魔杖冲进去看个究竟
   B 拉上几个朋友一起去壮胆
   C 假装没听见，赶紧离开
   D 报告教授，安全第一

❌ 我倾向于在危险面前表现勇敢
   A 非常同意  B 同意  C 不同意  D 非常不同意
```

第二种是心理量表，用户做起来像填问卷，做完没有分享欲。带魔法场景（禁林、魔杖、级长、魁地奇）能让哈迷会心一笑，路人也觉得新鲜。

### 结构要求

- **16 题**，每题 4 个选项（3 个太少不够分化，5 个太多开始烦躁）
- 每题只影响 **1 个维度**（`effect` 数组只有一位非零），这样维度之间不互相污染
- **每个维度 4 道题**，得分范围 -4 ~ +4
- 选项要有**真实的两难**，不要有明显的"正确答案"
- **每维 4 题里至少 1 题带 0 分中性选项**，补出中间态，让四维可达点从 5^4=625 提升到 9^4=6561，学院分布更均衡

### 维度覆盖检查

```
D1（勇气）: q1, q5, q9, q13
D2（野心）: q2, q6, q10, q14
D3（理性）: q3, q7, q11, q15
D4（忠诚）: q4, q8, q12, q16
```

## 四、写结果文案（每个学院五个字段，缺一不可）

| 字段 | 作用 | 长度 | 示例 |
|---|---|---|---|
| `title` | 定调标签，一眼记住 | 4–6 字 | 勇气与胆识 |
| `tagline` | 金句，可截图传播 | 12–20 字 | 我们纵身跃入火海，因为那里有值得守护的人 |
| `traits` | 3 个相似点，制造"被看穿"感 | 每条 10–18 字 | 冲在最前面，越危险越兴奋 |
| `advice` | 人生建议，给情绪价值 | 15–25 字 | 你的勇敢很珍贵，但别忘了给同伴留一个并肩的位置 |
| 学院动物 + 创办人 | 增加考据感，哈迷会心 | 短 | 狮子 · 戈德里克·格兰芬多 |

### 写作要点

- **第二人称"你"**，不要用"该类型的人"
- **写具体行为，不写抽象性格**。"冲在最前面"比"勇敢"有画面感
- **带一点冒犯或自嘲**，纯夸的文案没人转发
- **advice 要给出出路**，不要只描述问题
- **金句要能脱离哈利波特成立**——路人看不懂魔法梗也能被打动，哈迷又能品出彩蛋

### 学院文案自检（重点）

| 学院 | ❌ 常见写错 | ✅ 正确共识 |
|---|---|---|
| 格兰芬多 | 只会莽、没脑子 | 勇敢、重情义，为守护而冲 |
| 斯莱特林 | 坏、邪恶、不择手段 | 野心、精明、目标感强 |
| 拉文克劳 | 书呆子、冷漠 | 好奇心、理性、享受思考 |
| 赫奇帕奇 | 平庸、没存在感 | 忠诚、靠谱、踏实勤勉 |

**斯莱特林和赫奇帕奇是重灾区。** 写之前先过一遍：一个 10 年哈迷看了会点头还是会骂。

## 五、验证可达性与分布

**上线前必做。** 计分空间是离散的，粗暴设计的向量会导致部分学院永远匹配不到。

```bash
node tools/verify-reach.js
```

脚本穷举所有可达答案组合，统计每个学院被匹配的次数。4 个学院理想各约 25%。

参考实现的分割线：

- **单学院不超过 35%**，否则用户会觉得"怎么测都是它"
- **最低的不低于 15%**，否则等于花钱写了一份没人看得到的文案

不均衡就调 `vector`（往可达点附近靠）或加 0 分选项，调完重跑。

## 六、晒单文案

用户测完想发，但不知道写什么。给他现成的，转化率明显提升。

模板要素：

```
分院帽说：我属于{name}🪄 {title}

「{tagline}」

16 道题测出你的霍格沃茨学院，你也来分院？

#霍格沃茨 #分院帽 #性格测试
```

要点：
- 第一人称，带一点得意或自嘲（"我居然是斯莱特林"这种反差最有传播力）
- 保留金句，这是最容易被转发的部分
- 明确 CTA："你也来分院"
- 带 3–5 个话题标签
- 用 `🪄` 这类魔法 emoji 增加记忆点（但别堆太多）
